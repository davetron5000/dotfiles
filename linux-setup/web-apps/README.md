This all requires the FirefoxPWA extension to be set up and configured.  THIS requires that you install Firefox from
their PPA and not snap or flatpak or whatever else.

Once that's set up, the named scripts will set up the PWA.  They should launch the PWA, but you should quit them
immediately, then run ./configure.sh with the name of the PWA (see script for name).  This will add additional
configuration that can't be done on setup.

And then you have my permission to die.
